# 📄 CV Maria Server (Portfolio CV Dinámico)

Aplicación web desarrollada como parte de los proyectos del Ciclo Superior de **Desarrollo de Aplicaciones Web (DAW)**, diseñada para mostrar un currículum vitae interactivo y gestionado desde el entorno servidor.

## 🚀 Características principales
* **Estructura Modular en Servidor:** Organizado para procesar solicitudes y mostrar la información profesional de forma dinámica mediante PHP.
* **Diseño UI/UX Limpio:** Interfaz profesional y minimalista optimizada para la lectura de perfiles técnicos y laborales.
* **Preparado para Producción:** Configurado para ejecutarse de manera fluida en entornos de servidor local (XAMPP / Apache) o desplegado en servidores cloud.

## 🛠️ Tecnologías utilizadas
* PHP 8+
* HTML5 / CSS3 (Diseño responsivo y adaptado)
* Git y GitHub (Control de versiones)
